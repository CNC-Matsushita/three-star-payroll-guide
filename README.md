# スリースター 月次給与運用手順

勤怠給与管理システム（総務・経理）の月次運用手順書です。

公開ページ: https://cnc-matsushita.github.io/three-star-payroll-guide/

`index.html` 単体で完結しています。画像はすべて data URI として埋め込み済みで、外部への通信は Google Fonts のみです。

## 収録内容

- 依存関係マップ — 帳票の作成順序と、上流変更が下流に伝播する経路
- STEP 00〜07 — マスタ整備／シフト確定／売上計算書／時給者支払／歩合給計算書・現場経費／現場台帳／自動生成帳票／給与公開
- 有給管理、年次・随時作業
- 再計算ルール早見表
- つまずきポイント（症状から原因を引く）
- 付録 — 未確定事項、アクセス情報、動作環境、関連ドキュメント

## 注意

- 管理画面のアカウントとパスワードは本ページに記載していません。管理者から個別に受け取ってください。
- 画面キャプチャは既存の利用ガイドから流用したうえで、従業員名・現場名・会社名を復元できない形でマスク処理しています（金額はそのまま残しています）。
